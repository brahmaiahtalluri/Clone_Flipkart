🛒 Flipkart Clone – Frontend Project

A simple and responsive Flipkart UI Clone built using modern frontend technologies.
This project recreates the look and feel of the Flipkart homepage, focusing on layout design, navigation bar, product sections, and responsive styling.

🚀 Features

🔵 Flipkart-style Navbar

🖼️ Banner Slider / Static Banner (based on your project)

📦 Product Cards Section

📱 Fully Responsive Design

🎨 Clean and modern UI

🌐 Compatible with all screen sizes
